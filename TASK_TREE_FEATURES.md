**View Modes and Organization**
The Task Tree system offers three distinct visualization modes including a Daily view that organizes tasks chronologically by date, a Weekly view that aggregates tasks into weekly clusters before breaking them down by individual days, and a Project view that hierarchically structures tasks first by their associated project and then by the specific date they are assigned to. Users can seamlessly toggle between these views using the Tab key to find the most appropriate context for their current workflow, whether they need to see what is due today, plan for the upcoming week, or focus on a specific project's roadmap. Additionally, a specialized Backlog view can be activated to aggregate and display all pending tasks from the past up to the current date, ensuring that no unfinished work is forgotten or lost in the history. For users requiring deep focus, the system provides an Isolation Mode which allows the user to lock the view onto a specific Project, a specific Date, or a combination of both, effectively hiding all unrelated tasks and noise from the screen. To manage screen real estate and cognitive load, the interface supports dynamic expansion and collapsing of all tree nodes, including broad groups, specific projects, weekly aggregations, and daily lists, with global commands available to instantly expand or collapse the entire tree structure at once.

**Task Management and Manipulation**
The core functionality revolves around comprehensive Create, Read, Update, and Delete operations that allow users to add new tasks via detailed dialogs or quick-add prompts, edit existing task details, change priorities on the fly, and permanently remove tasks that are no longer relevant. A sophisticated Priority System is embedded within the list, allowing tasks to be ranked from level 1 to 5, which directly influences their sorting order to ensure that the most critical items always appear at the top of their respective lists. Users can instantly mark specific tasks as "focused" by pressing the 'f' key, which adds them to a dedicated "Quick Start List" visible in the main Timer view, bridging the gap between planning and active execution. Tasks can be tagged with custom keywords for organization, and the system supports a powerful Move to Today feature that instantly reschedules any selected task to the current date with a single keystroke, facilitating rapid daily planning. The status of a task can be toggled between Pending and Done using the Enter key, and when a task is marked as complete, the system intelligently prompts the user to log the duration of the work, seamlessly integrating task management with time tracking.

**Advanced Filtering and Search**
To help users navigate large volumes of tasks, the system implements a robust Filtering engine that can narrow down the visible list based on multiple criteria simultaneously, including specific tags, task status (Pending or Done), minimum priority levels, and even the inclusion or exclusion of tagless items. This filtering capability is visually indicated in the interface, ensuring the user is always aware when they are viewing a subset of their total workload. Complementing this is a fuzzy search mechanism used in various selection contexts, allowing users to quickly find projects and tasks by typing partial matches, which is particularly useful when assigning tasks to projects or initiating quick sessions.

**User Interaction and Visual Feedback**
The interface is designed with a keyboard-centric philosophy, utilizing standard arrow keys for navigation alongside Vim-style j and k bindings for efficiency, ensuring that power users can traverse the tree without ever reaching for a mouse. A suite of single-key shortcuts empowers the user to perform complex actions instantly, such as pressing 's' to immediately start a timer for the selected task, 'Space' to open a detailed Neo-brutalist card popup showing comprehensive task metadata, or 'u' to undo the last destructive action like a deletion. Visual feedback is prioritized through a Neo-brutalist design aesthetic that employs bold borders, high-contrast colors derived from project assignments, and distinct indentation to clearly represent the hierarchical tree structure. The system also provides immediate visual cues for state changes, such as flashing the task row when its priority is updated and displaying progress indicators that show the ratio of completed to total tasks for every group, week, or project node.

**Integration with Timer and History**
The Task Tree is not an isolated component but is deeply integrated with the core Timer and History systems of the application, meaning that completing a task in the tree can automatically generate a session log in the history. Conversely, the Timer view can directly access "focused" tasks from the tree, allowing for a smooth transition from selecting a piece of work to actively tracking time against it. This tight coupling ensures that the planning performed in the Task Tree directly drives the productivity metrics and analytics visualized in other parts of the application like the Heatmap and Weekly Dungeon views.
